# 示例 · 速通模式

> 演示：用户说「整卷速通」。同一份输入（见 `demo-chapter.md`），跳过 Gate 与逐批停顿。
>
> 规则：选择题、判断题、填空题**只给答案**并紧凑连排；简答、计算、编程、材料分析**完整作答**；存疑题从紧凑行移出并单独展开。

---

## 输出

```
## 速通 · 第二章 数据通信基础 · p.9–16 · 共 7 题

**客观题与填空题（只给答案）**
1.A　2.D　3.ABC　4.错误　5.①W·log₂(1+S/N) ②信道带宽（Hz）
（⚠️ 第 7 题存疑，见下方说明）

**简答题（完整作答）**
6.
答案：
　① 相同点：两者都在每个码元中间产生电平跳变，均具备自同步能力。
　② 区别：曼彻斯特以"中间跳变方向"表示数据，差分曼彻斯特以"码元起始处有无跳变"表示数据，中间跳变仅用于同步。
　③ 优劣：差分曼彻斯特抗干扰能力更强、对极性不敏感，但实现稍复杂；曼彻斯特实现简单，是 10BASE-T 的标准编码。
解析：得分点在"区别"与"优劣"两问，须分开作答；只答波形差异会漏掉抗干扰性的比较。
考点：两种曼彻斯特编码的编码规则与工程取舍

**存疑说明**
第 7 题：倾向答案 C ⚠️。原卷 p.16 选项 D 内容缺损，无法判断其表述。串行传输只需一条（或一对）
数据线，故 C 项作为"错误项"成立；但若 D 亦为错误表述，则本题有两个错误项、题目本身有误。
→ 请对照纸质原卷 p.16 第 7 题的 D 选项后再定。
```

> 若该章题量更大（如 20 道客观题），紧凑行按每行 10 题折行：
>
> ```
> 1.B　2.AC　3.正确　4.D　5.错误　6.BD　7.A　8.错误　9.C　10.ABC
> 11.D　12.正确　13.AD　14.B　15.错误　16.C　17.BD　18.A　19.错误　20.BC
> ```

## 与逐章模式的差异

| 维度 | 逐章模式 | 速通模式 |
|------|---------|---------|
| Gate | 先出清单等确认 | 跳过，直接答 |
| 停顿 | 一章一停 | 一次给完 |
| 选择/判断/填空 | 答案 + 解析 + 考点 + 复习 | **只有答案** |
| 简答/计算 | 完整作答 | 完整作答（不变） |
| 存疑题 | 题内标注 + 汇总表 | 从紧凑行移出，单独「存疑说明」节 |
| 顺序 | 原书顺序 | 原书顺序（不变） |
| 丢题检查 | 全覆盖 | 全覆盖（不变） |

**速通省的是阅读量和 token，不是正确性。** 顺序、存疑标注、不丢题三条底线一条都没松。
