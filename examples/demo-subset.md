# 示例 · 只答指定章节

> 演示：用户不想做全书，只要某一章。

---

## 场景 A · 用户明确指名

**用户**：帮我做一下这份题库，只要第三章的答案。

**处理**：

```
已定位：第三章 进程管理 · p.48–57 · 共 24 题 → 按常规逐章作答。
```

然后直接作答该章，**不出批次清单、不问速通**（范围已明确，清单没有决策价值）。

```
## 第三章 进程管理 · p.48–57 · 共 24 题

**1. B**
解析：进程是资源分配的基本单位，线程是调度的基本单位；A 项混淆两者，C 项描述的是程序而非进程。
考点：进程与线程的区别
复习：进程三种基本状态及转换条件

**2. AC**
解析：逐项判定——
　A 对：信号量初值为 1 时退化为互斥锁。
　B 错：P、V 操作本身不可中断，属于原语。
　C 对：管程把共享变量与操作封装，天然具备互斥。
　D 错：管程的同步仍需条件变量配合 wait/signal。
考点：信号量与管程
复习：P/V 语义；互斥与同步的区别；条件变量的使用时机

……

回复「继续」可进入下一批；说「导出」可生成当前累积答案。
```

---

## 场景 B · 用户列举了多章

**用户**：只要第三、五章。

**处理**：按原文顺序作答，一章一答，中间停下。

```
已定位 2 章：第三章 进程管理（p.48–57，24 题）、第五章 存储管理（p.78–86，19 题）
→ 按原书顺序作答，先第三章。
```

> 注意：即使你说的是"第五章、第三章"，也**按原书顺序**输出。答案次序必须和书对得上，否则翻书核对时会错位。

第三章作答完后停下，等「继续」再答第五章。

---

## 场景 C · 用户说法模糊（必须回问）

**用户**：帮我做一下重点章节。

**错误做法**：自行理解为"最后两章"或"考纲重点章"直接开答。

**正确处理**：回问，并**列出清单供点选**。

```
"重点章节"没有客观标准，我不替你猜——以下是有题目的章节，你点一下要哪些：

共 9 章 / 312 题

1/9  第一章 绪论          p.1–8     28 题（单选 20 / 多选 5 / 判断 3）
2/9  第二章 细胞结构      p.9–18    41 题（单选 25 / 多选 8 / 简答 8）
3/9  第三章 遗传基础      p.19–26   36 题（单选 18 / 多选 6 / 填空 4 / 计算 8）
...

也可以直接说页码（如 "p.19–40"），或说"最后一章"。
```

同类模糊说法一律回问：**"后面几章""主要的""常考的""最后一部分""核心部分"**。

## 场景 D · 指定章节 + 速通

**用户**：只要第三、五章，速通。

**处理**：仍出范围回执（一行），然后一次给完两章，客观题只给答案。

```
已定位 2 章：第三章 进程管理、第五章 存储管理 → 速通作答。

## 速通 · 第三章 进程管理 · p.48–57 · 24 题
```

## 本例体现的规则

| 规则 | 体现 |
|------|------|
| 范围优先于粒度 | 说了章节就只答该章，不问"要不要全书" |
| 指定范围跳过 Gate | 回一行范围确认即可，清单无决策价值 |
| 顺序守恒 | 用户列举顺序 ≠ 原文顺序时，按原文顺序输出并说明 |
| 模糊说法回问 | 不猜"重点章节"，列清单让用户点选 |
| 单章不停顿 | 只有一章时一次答完，不设中间停顿 |
| 多章一章一答 | 两章及以上，一章一答，中间等「继续」 |
