# 示例 · 逐章模式

> 演示：默认模式（全量 + 逐章 + 详细解析 + 批次 Gate）。

---

## 输入（`计算机网络基础题库.pdf` 第二章，p.9–16）

```
第二章  数据通信基础

1. 在 OSI 参考模型中，负责比特流透明传输的是（  ）
   A. 物理层    B. 数据链路层    C. 网络层    D. 传输层

2. 某信道带宽为 3 kHz，信噪比为 30 dB，根据香农定理，该信道的最大数据速率约为（  ）
   A. 3 kbit/s    B. 6 kbit/s    C. 30 kbit/s    D. 29.9 kbit/s

3. 下列关于曼彻斯特编码的说法，正确的有（  ）
   A. 每个码元中间都有电平跳变
   B. 可实现自同步
   C. 编码效率为 50%
   D. 抗干扰能力比差分曼彻斯特编码强

4. 在基带传输中，信号不经过调制直接传送，因此不需要考虑传输介质的带宽限制。（  ）

5. 香农定理的表达式为 C = ______，其中 W 表示 ______。

6. 简述曼彻斯特编码与差分曼彻斯特编码的区别，并说明各自的优缺点。

7. 下列关于串行传输的说法，错误的是（  ）
   A. 一次只传输一个比特
   B. 适合长距离通信
   C. 需要使用多条数据线
   D. （原文此处选项内容缺损）
```

## 第二步：作答

```
## 批次 1/1 · 第二章 数据通信基础 · p.9–16 · 共 7 题

**1. A**
解析：物理层处理的是比特流在介质上的透明传输，只关心电压、接口与速率；数据链路层才负责成帧与差错控制，B、C、D 均已向上封装。
考点：OSI 各层功能边界
复习：七层模型每层的 PDU 与典型设备

**2. D**
解析：本题考查香农定理，两步走。
　① 30 dB 换算：10lg(S/N) = 30 → S/N = 1000（不是 30，这是最常见的错点）。
　② 代入 C = W·log₂(1+S/N) = 3000 × log₂(1001) ≈ 3000 × 9.97 ≈ 29.9 kbit/s。
　③ 干扰项来源：A 项把带宽直接当速率，B 项用奈氏准则且误取 1 位/码元，C 项未做对数换算。
考点：香农定理 + dB 与信噪比换算
复习：C = W·log₂(1+S/N) 与奈氏准则 C = 2W·log₂N 的区别；dB 定义；两定理的适用前提

**3. ABC**
解析：逐项判定——
　A 对：曼彻斯特编码每个码元中间必有跳变，跳变本身携带时钟信息。
　B 对：正因如此可自同步，无需额外时钟线。
　C 对：每比特需两个码元，编码效率 50%。
　D 错：差分曼彻斯特以"起始有无跳变"表示数据，抗干扰能力强于曼彻斯特。
考点：曼彻斯特编码与差分曼彻斯特编码
复习：两种编码的波形差异；编码效率计算；自同步原理

**4. 错误**
解析：基带传输虽不经调制，但介质带宽仍限制最高码元速率，长距离还会引入衰减与码间串扰。
考点：基带传输的约束条件

**5. ①W·log₂(1+S/N) ②信道带宽（单位 Hz）**
解析：香农定理给出有噪声信道的极限速率，与码元种类无关；W 是带宽而非频率，单位必须写 Hz。
考点：香农定理的符号含义
复习：与奈氏准则的对照记忆（前者含噪声，后者理想无噪声）

**6.**
答案：
　① 相同点：两者都在每个码元中间产生电平跳变，均具备自同步能力。
　② 区别：曼彻斯特以"中间跳变方向"表示数据，差分曼彻斯特以"码元起始处有无跳变"表示数据，中间跳变仅用于同步。
　③ 优劣：差分曼彻斯特抗干扰能力更强、对极性不敏感，但实现稍复杂；曼彻斯特实现简单，是 10BASE-T 的标准编码。
解析：本题得分点在"区别"与"优劣"两问，作答须分开写；只答波形差异会漏掉抗干扰性的比较。
考点：两种曼彻斯特编码的编码规则与工程取舍
复习：编码效率（均为 50%）；以太网各标准的编码方式对照

**7. C ⚠️不确定，建议复核**
解析：串行传输逐位送出，只需一条（或一对）数据线，故 C 项"需要使用多条数据线"描述的是并行传输，作为"错误项"成立；A、B 均符合串行传输特征。
不确定点：原卷第 16 页选项 D 内容缺损，无法判断其表述。若 D 也为错误表述，则本题存在两个错误项、题目本身有误。
→ 请对照纸质原卷 p.16 第 7 题的 D 选项后再定；若 D 错误，本题应视为"题意有误"，而非单选。

回复「继续」可进入下一批；说「导出」可生成当前累积答案。
```

## 本例体现的规则

| 规则 | 体现 |
|------|------|
| 批次 Gate | 先给清单再作答 |
| 复杂度自适应 | 第 2 题（公式+换算+干扰辨析）展开到三层；第 1 题只给一句依据 |
| 多选逐项判定 | 第 3 题四个选项逐条给对错理由 |
| 存疑标注 | 第 7 题给倾向答案 C，同时说明"D 缺损"这一翻转条件 |
| 存疑不凑答案 | 明确指出可能是"题目有误"，而非硬选 C 了事 |
| 导航行 | 末尾一行，不与正文混排 |
