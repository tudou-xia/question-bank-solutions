# 切分与清洗 · Splitting & Cleaning

决定答案质量的不是解题能力，而是**切分是否对**。切错一章，后面全错。本文件记录切分的判定细节、正则族、以及题库文档的常见脏数据。

## 1. 判定顺序

```
格式探测 → 文本抽取 → 水印剔除 → 题目边界识别 → 题号连续性校验
        → 章节结构识别 →（无章节则按页）→ 批次清单
```

顺序不可调换。尤其**水印必须先于题目边界识别**：否则水印里的字母会被当成选项，水印里的数字会被当成题号。

---

## 2. 章节标题正则族

按优先级依次尝试，命中即停。

| 优先级 | 模式 | 示例 | 备注 |
|--------|------|------|------|
| 1 | `^第[一二三四五六七八九十百零〇\d]+章` | 第三章 遗传基础 | 中文教材最常见 |
| 2 | `^第[一二三四五六七八九十百零〇\d]+节` | 第二节 孟德尔定律 | 常为章的下一级，视题量决定是否作批次 |
| 3 | `^第[一二三四五六七八九十百零〇\d]+部分` | 第一部分 基础篇 | 大分区，常含多章 |
| 4 | `^(Chapter|CHAPTER)\s+\d+` | Chapter 3 Genetics | 英文教材 |
| 5 | `^(Part|PART|Unit|UNIT|Section|SECTION)\s+[\dIVX]+` | Part II | 同上 |
| 6 | `^(模块|专题|项目)[一二三四五六七八九十\d]+` | 专题三 电磁感应 | 教辅、职教常见 |
| 7 | `^[一二三四五六七八九十]+、` | 一、选择题 | **危险**：这通常是题型分组而非章节，见 §2.1 |
| 8 | 目录 / 书签大纲 | — | 结构化文档优先读大纲 |

### 2.1 题型分组 vs 章节，必须分清

`一、选择题　二、填空题　三、计算题` 是**题型分组**，不是章节。误判会让批次变成"全部选择题"和"全部填空题"，破坏顺序（C1）。

判别信号：
- 该行之后紧跟的是题号 `1. 2. 3.` 且**题号从 1 重新开始**，且该分组内题型单一 → 题型分组。
- 该行之后题号**继续递增**接续上一章 → 章节。
- 该行含"选择题/填空题/判断题/简答题/计算题/多选题"等题型词 → 题型分组。

处理：题型分组不切批次，仅记录题型，批次仍按章节（或按页）划分。

## 3. 题号与选项正则族

### 题号

```
^\s*(\d{1,3})\s*[.、)．]\s*          # 1.  1、  1)  1．
^\s*[(（]\s*(\d{1,3})\s*[)）]        # (1)  （1）
^\s*[\[【]\s*(\d{1,3})\s*[\]】]      # [1]  【1】
^\s*Q(\d{1,3})\b                     # Q1
^\s*Question\s+(\d{1,3})             # Question 1
```

### 选项

```
^\s*[(（]?[A-H][.、)）．]\s*          # A.  A、  A)  (A)  （A）
^\s*[A-H]\s*[.、]\s*                 # A. 变体
```

### 选项粘连的高发形态

```
A.光纤 B.双绞线 C.同轴电缆 D.无线       ← 一行内四个选项，需按位置切分
A．光纤　B．双绞线　C．同轴电缆          ← 全角点 + 全角空格
[A] 光纤  [B] 双绞线                    ← 方括号编号
A 光纤  B 双绞线                        ← 无分隔符，最危险
```

处理：同一行内出现 ≥2 个选项标记时按标记位置切分；切分后校验每个选项非空，若出现空选项则回退为整行保留并标 ⚠️。

## 4. 题号连续性校验

识别完边界后，必须验证：

1. **连续性**：题号应为 `1..N` 无跳号。跳号 → 可能漏检或原文本身跳号。
2. **单调性**：不得出现 `5, 6, 4, 7`。乱序 → 切分把题干里的编号误判成题号。
3. **重复性**：不得重复。重复 → 同一题被切了两次（常见于跨页重复）。
4. **数量匹配**：清单里声明的题量 = 实际识别题量。

任一校验失败时：
- 优先重跑切分（放宽/收紧正则）。
- 仍失败 → **显式报告**："第 3 章识别到 39 题，题号 12 之后直接跳到 15，疑似漏检 3 题或原文跳号，请核对 p.14"，而不是默默给出 39 题。

## 5. 水印剔除

题库文档几乎都带水印，这是解析质量的第一大杀手。

### 5.1 常见形态

| 形态 | 示例 | 危险点 |
|------|------|--------|
| 斜向半透明文字 | 「XX题库　内部资料　禁止外传」 | 斜穿题干中部，与文字交错 |
| 页脚 / 页边重复串 | 「www.example.com」每页底部 | 被当成题目内容 |
| 页眉机构名 + 编号 | 「XX教育 第 3 页」 | 与题号混淆 |
| 单字母水印 | 「A」重复铺满页面 | **被读成选项 A**（最高频错误） |
| 底纹图片 | 机构 Logo 半透明贴图 | OCR 出乱码字符 |
| 数字水印 | 学员编号「2024-0815」 | 被读成题号或答案 |

### 5.2 判定信号

满足任一即可判为水印，满足两条以上可直接剔除：

- **重复性**：同一字符串在多页/多题重复出现（跨题重复是最强信号——题干不可能每页都一样）。
- **位置**：固定在页边距、页脚、页眉，或呈固定角度倾斜。
- **语义**：与题干、选项无语法关系（不构成句子的一部分）。
- **样式**：字体、颜色、透明度与正文明显不同。

### 5.3 剔除流程

```
1. 标记候选水印串
2. 从题干与选项中删除该串
3. 重新拼接断行（删除后可能出现 "根据　定理" → "根据定理"）
4. 重跑题号连续性校验与选项完整性校验
5. 逐题快速通读，确认题干语义完整
```

第 4 步不可省。水印字母被删掉时，可能连带删掉了真正的选项标记；水印数字被删掉时，可能破坏题号序列。**只有重跑校验才能发现这类损伤。**

### 5.4 水印与内容重叠

若水印遮挡了题干关键内容（数字、公式、选项文字），导致无法确定原意：

- **不得脑补**。
- 输出 `⚠️` 并指明：「题干"带宽为 ___ kHz"处被水印遮挡，无法确定数值，请对照原卷 p.11」。
- 若该题因此无法作答，明确写"无法确定"而不是给一个凑出来的答案。

## 6. 表格型题库

很多教辅把题目排成表格（题干一列、答案一列、解析一列）。

处理要点：
- **必须读单元格**，不能只读文本流——否则题干与答案会被拼成一行。
- 识别列语义：若某列内容全是 `A/B/C/D` 或 `正确/错误`，该列为答案列；若某列是长文本且含"因为/由于/即"，多为解析列。
- **答案列是泄漏源**：若原文档自带答案列，优先采用该答案但**仍需独立验算**；若验算与该答案冲突 → 标 ⚠️ 并写出冲突点（这往往说明原答案有误，是很高的价值输出）。
- 若解析列已存在，不要照抄，重写为技能规定的解析结构（答案 → 分层推理 → 考点 → 复习）。

## 7. OCR 常见坑

| 坑 | 表现 | 处理 |
|----|------|------|
| 选项粘连 | `A.光纤B.双绞线C.同轴` | 按标记位置切分 |
| 数字误识 | `l` ↔ `1`，`O` ↔ `0`，`S` ↔ `5` | 在数值题中结合上下文校验；不确定标 ⚠️ |
| 上下标丢失 | `m2` 应为 `m²`，`log2` 应为 `log₂` | 按学科惯例还原，并在解析中写出完整式 |
| 公式错位 | 分式被压成一行 | 还原为行内表达式，必要时用代码块 |
| 跨页截断 | 题干在 p.9 尾、选项在 p.10 首 | 按题号归属合并，不按页硬切 |
| 双栏排版 | 左右栏交错读 | 先按 x 坐标聚类成栏，再逐栏读 |
| 图片题目 | 几何图形 / 电路图 | 描述图形内容后再作答；无法描述则标 ⚠️ |

## 8. 无章节结构的兜底

按优先级寻找分页依据：

1. PDF 物理页数（`p.N`）
2. 文档内打印页码（页脚数字）
3. 显式分页符 / 分节符
4. 以上皆无 → 按题量等分（`fixed:20` 之类），并在回执里说明"该文档无分页信息，已按每 20 题一批切分"

兜底时**必须在回执中说明切分依据**，让用户知道为什么这批是这些题。

---

## 9. 歧义处理原则

| 情况 | 处理 |
|------|------|
| 章节名歧义（目录编号与正文偏移） | 回问，给出两种编号的对照 |
| 用户说「重点章节」「后面几章」 | 回问，按清单格式列出章节供点选 |
| 同一章出现两次（跨页重复） | 去重，保留首次出现 |
| 章节存在但无题目 | 列入清单并标注"无题目"，不占批次 |
| 指定章节不存在 | 如实说明 + 列出可选章节 |

原则：**切分上的任何不确定，问一句的成本都远低于答错的成本。**
