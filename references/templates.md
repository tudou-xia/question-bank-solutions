## 3. 常规模式的各题型模板

### 3.1 简单单选 / 单选

```
**7. B**
解析：线粒体内膜向内折叠形成嵴，扩大附着面积，是有氧呼吸第三阶段的场所；A 为叶绿体，C 为高尔基体，D 无膜结构。
考点：细胞器结构与功能对应
复习：各细胞器的膜层数、主要功能、典型实例
```

### 3.2 复杂单选（多知识点 / 多步）

```
**19. C**
解析：本题考查光合作用与呼吸作用的耦合关系，需分三层看。
　① 光反应在类囊体膜上产 ATP 与 NADPH，暗反应在基质中消耗它们——题干"黑暗中持续 12 h"意味着光反应停止，ATP/NADPH 断供。
　② 暗反应虽不直接需要光，但缺 ATP/NADPH 后 C₃ 还原受阻，C₃ 积累、C₅ 减少，故 A、B 项方向相反，均错。
　③ D 项"有机物总量不变"忽略了呼吸作用仍在消耗，故错。C 项正确。
考点：光反应与暗反应的物质联系 + 暗期代谢判断
复习：ATP/NADPH 的去向；C₃/C₅ 动态变化表；光照骤停/骤增的经典曲线；呼吸作用与光合作用的昼夜关系
```

### 3.3 多选题

```
**12. ABD**
解析：逐项判定——
　A 对：曼彻斯特编码每个码元中间必有跳变，跳变本身携带时钟信息。
　B 对：正因如此可自同步，无需额外时钟线。
　C 对：每比特需两个码元，编码效率 50%。
　D 错：差分曼彻斯特以"起始有无跳变"表示数据，抗干扰能力强于曼彻斯特。
考点：曼彻斯特编码与差分曼彻斯特编码
复习：两种编码的波形差异；编码效率计算；自同步原理
```

### 3.4 判断题

```
**8. 错误**
解析：基带传输虽不经调制，但介质带宽仍限制最高码元速率，长距离还会引入衰减与码间串扰。
考点：基带传输的约束条件
```

### 3.5 填空题

```
**12. ①ATP ②线粒体基质 ③2**
解析：有氧呼吸第二阶段在线粒体基质进行，丙酮酸与水反应生成 CO₂ 和 [H]，释放少量能量。
考点：有氧呼吸三阶段的场所与产物
```

### 3.6 简答 / 论述

```
**23.**
答案：
　① 相同点：两者都在每个码元中间产生电平跳变，均具备自同步能力。
　② 区别：曼彻斯特以"中间跳变方向"表示数据，差分曼彻斯特以"码元起始处有无跳变"表示数据，中间跳变仅用于同步。
　③ 优劣：差分曼彻斯特抗干扰能力更强、对极性不敏感，但实现稍复杂；曼彻斯特实现简单，是 10BASE-T 的标准编码。
解析：本题得分点在"区别"与"优劣"两问，作答须分开写；只答波形差异会漏掉抗干扰性的比较。
考点：两种曼彻斯特编码的编码规则与工程取舍
复习：编码效率（均为 50%）；以太网各标准的编码方式对照
```

### 3.7 计算题

```
**23.**
答案：
  (1) 2.4 m/s²
  (2) 18 N
解析：思路——先由受力分析确定合力，再用牛顿第二定律求加速度；第二问注意摩擦力方向随运动方向变化。
　步骤：F合 = F − μmg = 12 − 0.2×6×10 = 0 → 需重新判断是否已达最大静摩擦…
　回代验证：a = F合/m = 14.4/6 = 2.4 m/s²，与答案一致。
考点：牛顿第二定律 + 摩擦力方向判断
复习：整体法与隔离法；静摩擦与滑动摩擦的切换条件
```

### 3.8 编程题

```
**31.**
答案：
```python
def two_sum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i
```
解析：用哈希表把"查找配对"从 O(n) 降到 O(1)，整体 O(n)/O(n)。注意先查后存，避免同一元素被用两次。
考点：哈希表空间换时间
复习：两数之和的暴力解法复杂度；重复元素与返回顺序的边界约定
```

### 3.9 材料分析

```
**35.**
答案：
　① 材料一反映的现象是……
　② 结合材料二，其成因在于……
　③ 综上，应采取的应对是……
解析：三步走——先定位材料中的关键句，再与教材概念对接，最后落到"措施/评价"层面。只描述材料不给概念对接会丢一半分。
考点：材料信息提取 + 概念迁移
复习：该类题型的通用答题框架（现象—成因—影响—对策）
```

## 4. 存疑题

```
**31. C ⚠️不确定，建议复核**
解析：……
不确定点：原卷第 14 页选项 D 在 OCR 中缺损，无法确认其表述。若 D 为"……"，本题应选 D。
→ 请对照纸质原卷第 31 题的 D 选项后再定。
```

三要素缺一不可：
1. **依据强度**（哪部分是确定的、哪部分是推断的）
2. **不确定来源**（OCR 缺损 / 题干歧义 / 多个来源冲突 / 题意本身有误）
3. **翻转条件**（什么情况下答案会变）

```

| 38 | A | 题干"不正确"疑为"正确" | 原卷 p.16 第 38 题 |

  第一章 绪论 ........ 1
  第二章 细胞结构 .... 5
  第三章 遗传基础 .... 12

  ...

要点：
- 封面必须写**范围**与**进度**，否则用户分不清这份是半成品还是完整版。
- 已答章节才进目录，未答章节不占位、不写"待补充"。
- 存疑汇总永远放最后一节，不散落在正文里。
- 两个粒度（详细 / 速通）各自独立成文件，**不做合并**。
